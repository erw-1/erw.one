# A note kept in its own file

This text lives in `assets/note.md`, not in a page. The reader shows it in place.

- **Image syntax** embeds the file as rendered Markdown.
- The title `"plaintext"` shows the same file as raw text.
- A normal link opens it, and `"download"` keeps a copy.

> Embedded notes run no scripts and are never part of the page tree.
